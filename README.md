# Agyion Quant Agent

### A market regime gauge that can act — within rules a contract enforces

Read the market. Compute the regime. Trade only what it is allowed to.

[Live site](https://agyion-quant-agent.vercel.app/) · [Vault on Fuji](https://testnet.snowtrace.io/address/0xd4D6fAcC84fC230b605522Bd21b9f2E82A01Fa50) · [Security report](vault/SECURITY_TEST_REPORT.md)

</div>

Agyion Quant Agent turns twenty-six weighted quantitative signals into one daily market gauge — **SELL / NEUTRAL / BUY** — and can execute the resulting allocation on a non-custodial Avalanche vault. The agent reads; the contract enforces. The agent may call whitelisted swap functions. It cannot withdraw, ever.

Built at the OKX TR × Team1 Avalanche Agentic Hackathon (Ankara, 17 October 2026).

**Current release: Avalanche Fuji testnet.** The vault is deployed and a full signal→queue→timelock→execute cycle completed on-chain. Real-money readiness, mainnet deployment and complete position privacy are not claims of this release.

## Four parts

### Engine — the gauge

Twenty-six components across three layers: a long-term cycle index (MVRV Z-Score, NUPL, Bull-Bear momentum, realized-price distance — computed from raw market/realized capitalization), a short-term derivatives index (funding, open interest, liquidation asymmetry, premium indices, Fear & Greed), and a macro regime layer (dollar index, VIX, 10Y yield). Every component is normalized to [-1, +1]; weights are evidence-classed, correlation-deduplicated and versioned (`weights_version` in every snapshot).

[Methodology](docs/WEIGHTING.md) · [Data contract](docs/CONTRACT.md)

### Policy — one canonical decision

Signal labels use Schmitt-trigger hysteresis (enter ±0.50, exit ±0.40) so the gauge does not flicker. When long- and short-term indices disagree, exposure is cut, not flipped. When both are negative, the agent goes to near-flat. When the macro regime reads risk-off, every target halves. The same policy file drives both execution surfaces.

[Policy specification](docs/POLICY.md)

### Vault — autonomy on a leash

The QuantVault contract (Fuji: [`0xd4D6...Fa50`](https://testnet.snowtrace.io/address/0xd4D6fAcC84fC230b605522Bd21b9f2E82A01Fa50)) holds user funds under explicit rules: a separate agent role may only call whitelisted `(target, selector)` pairs; trades sit in a 15-minute timelock queue a guardian can veto; a daily notional cap bounds the agent; users deposit and withdraw permissionlessly — including while paused.

[Contract](vault/contract/QuantVault.sol) · [Agent loop](vault/agent_loop.py) · [Deploy guide](vault/DEPLOY.md)

### Newsletter — the regime, in plain English

A daily brief (23:15 TRT) renders the indices for non-technical readers. Commentary is generated by an LLM whose every number must match the snapshot — a deterministic verification gate blocks publication otherwise; a template fallback publishes instead. The public brief only uses license-clean data sources; proprietary feed values stay in an internal draft.

[Sample issue](docs/sample-newsletter.md)

## What is verified

- The vault completed **19/19 adversarial test scenarios** on a real EVM: agent withdrawal attempts, non-whitelisted targets, daily-limit breaches, premature execution, guardian veto, and paused-mode operations all revert as specified; user deposits and withdrawals always succeed. [Report](vault/SECURITY_TEST_REPORT.md)
- On Fuji testnet, the agent recorded a live signal, queued a ~1,008 tUSDC trade, waited the full timelock, and executed: [executeTrade tx](https://testnet.snowtrace.io/tx/0x7a98e1ba648dde950afa53d44c62f2f91e043a28874af1b0a9e3af6e46e2760c). A 2,000 tUSDC deposit backs the vault.
- The OKX Agent Trade Kit integration ran over real MCP transport: 50 tools enumerated live; the BTC ticker from ATK deviated 0.033% from the engine's independent CryptoQuant price. [Integration proof](atk/INTEGRATION_PROOF.md)
- The policy layer passes 10/10 unit branches and 4/4 end-to-end trigger scenarios; the LLM commentary layer passes 15/15 publication-gate tests.
- A live architecture audit found one licensing blocker and four major inconsistencies; all were fixed and re-verified before this release. The audit trail is retained under `verifier/`.

## Honest boundaries

- eERC position privacy is on the roadmap; this release does not hide positions.
- The newsletter's paid tier is designed to be license-clean (CC BY-NC feeds are internal-only). The demo itself is non-commercial.
- Autonomous execution ships with a human-approval mode; regulatory frameworks (SPK III-35/B.2, MiCA) treat autonomous portfolio management as licensed activity. We designed for that boundary deliberately.
- Sandbox networking blocked some free data hosts during development (CoinGecko, Binance, Etherscan); those fetchers degrade gracefully and activate in production.

## OKX.ai roadmap

The agent is designed to list on OKX.ai as an ASP (Agent Service Provider): the free daily brief as the marketplace service, paid tiers off-platform. OKX ATK serves the CEX showcase today; OnchainOS is the planned on-chain execution path.
